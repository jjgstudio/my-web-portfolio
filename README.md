# JJG Studio Portfolio

A responsive React and Vite portfolio for an independent web developer.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`; preview it with `npm run preview`.

## Before launch

Replace `your-email@example.com` in `src/main.jsx` with a real contact address. The Apex Auto Detailing card is configured in the `projects` array near the top of that file, so additional projects can be added as entries there.
